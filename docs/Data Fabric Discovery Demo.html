How to prove it with your own users

  1. Collect 20 real mission questions from analysts and program offices.
  2. Have two data stewards mark which layers a good answer must contain.
  3. Run each question through the portal search and the fabric. Compare how many right layers appear in the top 10 and how long analysts take to find a usable set.
  4. Add one build-out: the fabric returns a map-ready bundle for the winning set (service URLs, join keys, access steps).

How this demo was made

Keyword side: a simple keyword matcher over title, tags, summary and description in both catalogs, ranked by matched words with title matches weighted double. Real ArcGIS Hub ranking is more refined, but it also matches on words, not meaning.

Fabric side: prepared by Claude from the catalog fields, not produced by a live model in this page. Every layer name, date, authoritative flag and access flag is read from your files. The "why" text and the exclusions are my judgments and should be reviewed by a data steward. Whether a layer's geometry truly covers a given area was not checked, only its metadata.

Federal file: its filename says "faked", so treat the federal records as sample data. DC "updated" dates use the portal item's modified date because the DC catalog has no update date.
